# Modulo-Seguridad
Modulo de Seguridad con Java Spring Boot
Este proyecto contiene proyecto elaborado con Java Spring Boot para el backend y para el frontend utilizamos, HTML, CSS, JavaScript.
Se manejaron 4 tablas de una Base de Datos en PostgreSQL Rol Usuario Tipo Privacidad y Rol Fan Page.
Para cada tabla se realizaron los métodos de: agregar, buscar, listar, modificar y eliminar.
Se emplearon los métodos propios que se desarrollaron en SQL en vez de utilizar los métodos básicos de Spring.
